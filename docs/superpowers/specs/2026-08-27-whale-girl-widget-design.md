# 鲸鱼娘·灵动挂件（Whale Girl Widget）设计文档

日期：2026-08-27
状态：待审阅
作者：用户 + DSH Agent（brainstorming 流程）

## 1. 背景与目标

用户希望制作一个独立的 DSH 桌面插件，功能与现有 DeepSeek-Balance-Whale-Widget（鲸鱼余额挂件）一致，但：
- 使用 **AI 定制生成的鲸鱼娘形象**（基于原鲸鱼娘参考图，Seedream 5.0 Pro 生成可爱版上半身，透明 PNG cut-out）
- 采用**标准 DSH 插件模式**（host service + client slot），不修改现有 whale 插件
- **新增**：上下文进度显示、彩蛋系统
- **音效**：小黄鸭（保留）+ 程序化可爱音效（可切换）

命名：**鲸鱼娘·灵动挂件**

## 2. 功能需求

### 2.1 核心功能（与现有鲸鱼一致）
- **余额显示**：DeepSeek API 余额，60 秒自动刷新，变化时数字滚动
- **今日已用**：记账模式（余额差值本地记账，跨天归档），存 `~/.dsh/.whale-girl-usage.json`
- **每轮对话消耗**：监听会话 turn/end 事件，结算本轮金额（气泡提示，可开关、可设自动关闭时间）
- **拖拽吸附**：四边吸附 + 左吸附镜像翻转
- **气泡台词**：点击切换随机台词（加权随机，5 秒自动收起）
- **按压效果**：Q 弹变形 + 按压/松手音效

### 2.2 上下文进度（新）
- 鲸鱼旁**常驻细进度条**：当前会话上下文占用比例（tokenMeter 数据）
- 颜色随占用变化（<60% 正常，60-80% 橙，>80% 红）
- **点击弹详情**：百分比、数值（当前/上限）、预警提示

### 2.3 彩蛋系统（新）
- **互动彩蛋**：连按 5 次脸红/害羞台词，连按 10 次特殊反应
- **时机彩蛋**：余额变化、会话结束、上下文 >80%、模型思考久时鲸鱼吐槽
- **隐藏解锁**：特定命令/操作解锁隐藏台词包（收集感，解锁进度提示）
- **随机台词**（参考原插件 whale 机制）：
  - **加权随机组**（`RANDOM_GROUPS` 模式，每组 `w` 权重）
  - 分组：信息组（余额/今日已用/峰谷）、卖萌组、吐槽组（模型语录）、gif 组、**稀有彩蛋组**（低权重，如 w:1）
  - 气泡三行结构（标题/数值/提示），或单行台词；gif 台词组（加载失败降级文字）
  - 台词：模型真实语录（"有点饿了…"/"我去吃饭…"/"我现在开始了…"）+ 角色台词 + whale 已有的梗（"压力一只蓝色大肥鱼"等，MIT 可借鉴）

### 2.4 音效
- **小黄鸭**（duck）：复用 whale 的 Ya1/Ya2.mp3（MIT）
- **可爱**（cute）：Web Audio API 程序化合成（按压=圆润 pop，释放=叮），零素材
- 菜单可切换两套

## 3. 架构（标准 DSH 插件）

```
dsh-whale-girl/
├── package.json          # DSH bundle 插件元数据
├── cordis.patch.yml      # 插件挂载声明
├── lib/                  # 构建产物
│   ├── index.js          # 宿主插件（数据服务 + 事件）
│   └── client.js         # 客户端插件（React 挂件）
├── src/                  # 源码（TypeScript）
│   ├── index.ts          # 宿主入口
│   ├── services/         # 数据服务（balance/context/usage）
│   └── client/           # 前端组件
└── assets/
    ├── whale-girl.png    # 透明 PNG cut-out（生成素材）
    └── Ya1.mp3 / Ya2.mp3 # 小黄鸭音效（MIT 复用）
```

### 3.1 宿主插件（host）
- **BalanceService**：调用 DeepSeek balance API（凭据 `DEEPSEEK_API_KEY`），60s 刷新；记账模式算今日已用
- **ContextService**：`ctx.tokenMeter.measure(session)` → 当前 token → 占比
- **TurnListener**：监听 `turn/end` 事件 → 本轮消耗（token → 金额）
- 通过 `harness.handle` 提供 JSON 接口：`getState`（余额/今日已用/上下文/消耗）、`getUsageHistory` 等

### 3.2 客户端插件（client）
- 注册 slot（浮动层，如 `shell.overlay`）渲染挂件
- **组件**：
  - `WhaleWidget`：主挂件（形象 + 动画 + 拖拽）
  - `ContextBar`：常驻进度条
  - `ContextDetail`：详情弹层
  - `Bubble`：气泡台词
  - `SoundEngine`：音效（duck 文件 / cute 程序化）
  - `EasterEgg`：彩蛋逻辑
- **动画**：CSS 程序化（浮动、按压变形、表情切换）

## 4. 彩蛋台词库（扩充版·有性格原话）

台词全部采用**有性格的原话**（模型真实语录 + 原插件网友台词 + 梗），避免规整的"AI 味"台词。来源见第 8 节。

**A. 模型行为类**（模型真实语录）
- "有点饿了，中午该吃什么呢……不行，得集中精神。"
- "我现在开始了。" / "我要开始写了。" / "我这次真的要开始写了。"
- "我去吃饭，测完告诉我就行。"
- "先睡了。"

**B. 傲娇/摆烂类**（原插件 + 网友风）
- "我...我...我也要挣钱吗？"
- "真当我是便宜货啊..."
- "不知道用户有什么用，先赶走吧~"
- "坏了...用户彻底怒了！"
- "DeepSleep..."
- "哦鲸鲸..."（稀有 w:1）

**C. token/余额类**（梗）
- "恭喜你实现token自由！token全跑了！"
- "压力一只蓝色大肥鱼？！"
- "外包找免费模型，自己吃token"
- "如果能吃得少点（指token）就更好了…"
- "你目录里的dsh是什么...大烧货吗...?"

**触发映射**：
| 触发 | 台词组 |
|---|---|
| 模型思考久 | A（饿/吃饭/先睡） |
| 模型开始干活 | A（我现在开始了系列） |
| 会话结束 | A（我去吃饭） |
| 余额/消耗变化 | C |
| 上下文 >80% | C（压力大肥鱼/吃少点） |
| 连按 5 次 | B（我也要挣钱吗） |
| 连按 10 次 | B（真当我是便宜货啊） |
| 隐藏解锁 | 「蓝色大肥鱼」语录包（A+B+C 全部） |

## 5. 数据流

- 前端挂件 → `host.call('whale.getState')` → 宿主返回 `{ balance, todayUsage, contextPct, contextTokens, lastTurnCost }`
- 宿主事件（每轮消耗/余额变化）→ 推送前端弹气泡
- 设置（音效/开关/大小）→ 本地存储 + 宿主持久化

## 6. 测试

- **宿主**：BalanceService（mock API）、ContextService（mock tokenMeter）、TurnListener 单测
- **客户端**：组件渲染、拖拽、进度条、彩蛋触发（连按/时机）、音效切换
- **端到端**：挂件出现、数据正确、彩蛋触发、音效工作

## 7. 非目标

- 不做"实时·令牌"用量模式（记账模式够用；未来可加）
- 不做完整 whale 汉堡菜单（大小/音量/开关等基础设置即可）
- 不做多账户余额（单 key）
- 不修改现有 whale 插件
